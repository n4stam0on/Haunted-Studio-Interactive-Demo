# The Haunted Studio

This is an interactive incident response simulator demo built for the **Spooky Security** cybersecurity awareness event (October 29, 2026).

Players are the newest security analyst at Graveyard Games, a fictional game studio days from launch. Each run draws a case file based on a real attack on the video game industry and walks through three stations:

1. **The Call** – handle the first contact (a phone call, email, text, or chat message) and spot the social engineering.
2. **Log Hunt** – review a simplified sign-in, audit, or endpoint log and flag the suspicious entries.
3. **Break the Chain** – choose containment actions, then see where the attack was stopped on the Cyber Kill Chain.

**Team mode:** 2–4 players share one screen. Each takes a SOC role (Help Desk Lead, Threat Hunter, Incident Commander, Communications Lead) and leads one station while the team huddles. Team scores go on a local leaderboard.

The debrief reveals the real incident and maps it to MITRE ATT&CK techniques.

## Case files

| Case | Difficulty | Based on |
|---|---|---|
| The Midnight Caller | Easy | EA (2021) |
| The Text from Beyond | Easy | Activision (2022) |
| The Cursed Launcher | Medium | 2K (2022) |
| The Stolen Shield | Hard | Riot Games (2023) |
| The Locked Crypt | Hard | CD Projekt Red (2021) |

Names, logs, and messages are invented. Incident summaries reflect public reporting.

## Run it

Open `index.html` in any browser. No install or internet required beyond the web fonts.

This is phase one of a capstone project on security operations for live-service games.
